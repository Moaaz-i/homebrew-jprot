# Moaaz-i Jprot

## How do I install these formulae?

`brew install moaaz-i/jprot/<formula>`

Or `brew tap moaaz-i/jprot` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "moaaz-i/jprot"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
